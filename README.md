# 3DCAD Studio

Windows / macOS / Linux で動くパラメトリック 3D CAD アプリケーションです。Autodesk Inventor と同じ考え方・操作感
(スケッチ → フィーチャ → パラメータ、モデル ブラウザ、ViewCube、マーキング メニュー、
アセンブリ拘束) で部品と組立を設計でき、**STEP (AP214) で Inventor とデータを相互にやり取り**できます。

ジオメトリ カーネルには産業用 B-rep カーネル **OpenCascade** (replicad 経由の WebAssembly) を使用しているため、
フィレット・シェル・ブール演算などは近似ではなく正確なソリッドとして計算されます。

## デスクトップ アプリ (Windows / macOS / Linux)

3DCAD Studio はインストールして使うデスクトップ アプリケーションです (Electron)。
インターネット接続は不要で、ジオメトリ カーネルを含むすべてがアプリに同梱されています。

| OS | 配布ファイル |
| --- | --- |
| Windows 10 / 11 (x64) | `3DCAD-Studio-Setup-<版>.exe` |
| macOS (Intel / Apple シリコン) | `3DCAD-Studio-<版>-mac-arm64.dmg` (Apple シリコン) / `3DCAD-Studio-<版>-mac-x64.dmg` (Intel) |
| Linux (x64) | `3DCAD-Studio-<版>-linux-x86_64.AppImage` |

- `.3dcp` (パーツ) / `.3dca` (アセンブリ) がアプリに関連付けられ、ダブルクリックで開けます
- 保存・書き出しは OS の保存ダイアログで行います。未保存の変更がある状態で閉じると確認が表示されます
- GPU が使えない環境 (仮想マシン、リモート デスクトップ等) でもソフトウェア描画で起動します

### 配布ファイルの作り方

**GitHub Actions (推奨)** — `.github/workflows/release.yml`

- Actions タブ →「Desktop app」→「Run workflow」: 3 OS のインストーラを作成し、実行結果の Artifacts からダウンロードできます
- `v0.1.0` のようなタグを push: 上記に加えて GitHub Release を作成し、インストーラを添付します

**手元でビルド**

```bash
npm install
npm run app          # 開発用にアプリとして起動
npm run dist         # 実行中の OS 向けインストーラを release/ に作成
npm run dist:win     # Windows 向け (Windows 上で実行。Linux/macOS からは Wine が必要)
npm run dist:mac     # macOS 向け (macOS 上で実行)
npm run dist:linux   # Linux 向け
```

> コード署名証明書は設定していません。初回起動時に Windows SmartScreen の「詳細情報 → 実行」、
> macOS では「右クリック → 開く」が必要です。社内配布で警告を出さないようにするには、
> コード署名証明書 (Windows) / Apple Developer ID (macOS) を electron-builder に設定してください。


## できること

### パーツ (.ipt 相当)

| 分類 | 機能 |
| --- | --- |
| 2D スケッチ | 線分 (連続線)・円・3 点円弧・長方形・ポリゴン・長円・点、ジオメトリを投影、トリム、コンストラクション |
| 拘束 | 一致・水平・垂直・平行・直交・同一直線上・正接・等値・同心・中点・対称・固定、自動拘束 (端点スナップ / 水平・垂直推定) |
| 寸法 | 長さ・水平/垂直距離・点-線距離・直径・半径・角度。値は式 (`幅 / 2 + 5 mm` など)、過剰拘束時は従属寸法に自動切替、拘束状態 (残り自由度 / 完全拘束) を表示 |
| 作図中の数値入力 | 線分の長さ、円の直径、長方形の `幅 Tab 高さ` をその場で入力 (寸法も自動作成) |
| フィーチャ | 押し出し (距離 / 貫通 / 対称・反転、接合 / 切り取り / 交差 / 新規ソリッド)、回転 (全周 / 角度、コンストラクション線を軸として自動認識)、ロフト、スイープ、穴 (単純 / 座ぐり / 皿、面クリックで配置)、フィレット、面取り、シェル (内側 / 外側)、矩形状パターン (2 方向)、円形状パターン、ミラー、プリミティブ (直方体・円柱・球・トーラス)、作業平面 (オフセット)、ボディを移動 |
| パラメトリック | すべての寸法・フィーチャ値が `d0, d1, …` のモデル パラメータになり、パラメータ表 (fx) で式・ユーザ パラメータを編集可能。依存関係順に評価し、循環参照を検出 |
| 履歴 | モデル ブラウザ、フィーチャ編集 (ダブルクリック)、抑制、名前変更、パーツの終わり (ドラッグでロールバック)、元に戻す / やり直し |
| 編集時の参照追従 | フィレット等のエッジ / 面参照は寸法変更後も幾何学的に追従 (トポロジ ネーミング対策) |
| 検査 | 測定 (距離・角度・長さ・面積・半径)、iProperties (材質・質量・体積・表面積・重心・範囲) |

### アセンブリ (.iam 相当)

- パーツ (.3dcp) / STEP の配置、同じパーツの複数インスタンス、最初のコンポーネントを自動接地
- 拘束: **メイト・フラッシュ・挿入・軸合わせ・角度** (オフセット / 角度は式で指定可)
- ドラッグで自由移動・自由回転 (拘束は次の解決で再適用)
- コンテキスト内編集: コンポーネントをダブルクリック → パーツを編集 → 「アセンブリに戻る」で全インスタンスに反映
- 部品表 (BOM、CSV 書き出し)、干渉解析、アセンブリの STEP / STL 書き出し
- **自由度の表示**: 拘束のヤコビアンから各コンポーネントの残り自由度 (並進 / 回転) を計算し、ブラウザにバッジ、ステータスバーに合計を表示
- **拘束を駆動**: 角度 / オフセット拘束を開始値〜終了値で連続変化させて機構の動きを確認 (逆再生、干渉検出で自動停止、現在位置を保持)
- **ジョイント**: 剛性 (2 つのコンポーネントを現在の相対位置で一体化、自由度 0) とボール (点の一致、回転 3 自由度が残る) を追加
- **コンポーネント パターン**: 選択したコンポーネントを矩形状 (2 方向) / 円形状に配置。コピーは元に追従し (元を拘束・移動すると全体が移動)、自由度 0 として扱う
- **モーション解析 (運動学)**: 拘束の駆動を所要時間に割り当て、追跡コンポーネントの変位・速度・加速度と、他コンポーネントとの最小すき間をグラフ表示 (CSV 書き出し)。質量・力を考慮する動力学解析ではありません
- **分解 (プレゼンテーション)**: 挿入・軸合わせ拘束の軸方向 / 中心から放射状にコンポーネントを分解表示、軌跡線付き

### 形状編集

- **作業軸・作業点**: 原点の軸・直線エッジ・円形エッジ・円筒面の軸から作業軸を作成 (回転・コイルの軸に選択可、作成時の位置で固定)。作業点は座標 (式・パラメータ可) またはモデル上の点から作成
- **コイル**: スケッチのプロファイルを軸 (中心線・スケッチ軸) の周りにらせん状に掃引 (ピッチ・回転数・左巻き、新規 / 接合 / 切り取り)。ばね・ねじ山の実形状に (体積を理論値と照合する自動テスト付き)
- **文字 (刻印 / エンボス)**: スケッチ平面に日本語を含む文字を彫り込み / 浮き出し (IPA P ゴシック、高さ・回転・深さ指定)
- **3D パス (スイープ)**: スイープのパスに 3D 座標の点列を直接入力し、角を曲げ半径で丸めた配管・線材形状を作成
- **リブ**: 開いたスケッチ線とボディの間を自動で埋める補強リブ (スケッチ平面に対称な厚み)
- **勾配 (ドラフト)**: 固定面 (中立面) を基準に面へ抜き勾配
- **分割**: 原点平面・作業平面・モデルの平面でボディを分割 (片側 / 両方を残す)
- **厚み付け**: 平面に厚みをつけて接合 / 切り取り / 新規ソリッド
- **フレーム ジェネレータ**: スケッチの線分に沿って JIS 規格鋼材 (角形鋼管・長方形鋼管・鋼管・等辺山形鋼・溝形鋼・H 形鋼・平鋼) を配置。2 本が接する端部は留め継ぎ (マイター)、断面の回転指定。部材ごとに別ボディ。**部材表 (切断リスト)**: 断面・長さ・端部角度・数量・質量を集計し CSV 書き出し (T 継手の突き当て部のトリムは未対応)
- **溶接 (隅肉)**: 選択した直線エッジ (部材同士の T 継手・角継手の根元、入隅) に脚長を指定した三角形断面の溶接ビードを作成 (質量に反映)

### 改訂管理

- 「管理 → 改訂履歴」で版 (A, B, C … I・O は使わない) を記録。モデルの定義 (フィーチャ・パラメータ・材料) をファイル内に保存
- 版ごとの変更点 (寸法変更・フィーチャの追加 / 削除 / 変更・材料変更) を自動で一覧表示し、最新版からの未記録の変更も表示
- 任意の版に復元 (元に戻す で取り消し可)。図面の表題欄の「版」と改訂表に反映

### ねじ・標準部品 (コンテンツ センター相当)

- **穴コマンドの規格穴**: 単純穴 / キリ穴 (ボルト用、ISO 273 の 1〜3 級) / ねじ穴 (タップ)。呼びを選ぶと下穴径・キリ穴径・座ぐり (JIS B 1176) が自動で入ります
- **ねじフィーチャ (T)**: 円筒面 (軸・穴) におねじ / めねじを設定。呼びは面の直径から自動選択、長さ・オフセット指定可
- ねじ規格: ISO メートル並目 M1.6〜M48、細目、ユニファイ UNC / UNF
- 3D ではねじ山をらせん線で表示、図面では JIS B 0002 の略画法 (谷径の細線・3/4 円) で描画し、穴注記に「4×M6 深さ12」のように呼びが入ります
- **標準部品ライブラリ**: 六角穴付きボルト (ISO 4762)、六角ボルト (ISO 4017)、六角ナット (ISO 4032)、平座金 (ISO 7089)、平行ピン (ISO 2338)、深溝玉軸受 (60xx / 62xx)。寸法はユーザー パラメータ付きのパーツとして生成され、アセンブリに直接配置できます (同じ部品は部品表で数量がまとまります)

### 板金 (Inventor シートメタル相当)

- **板金スタイル**: 板厚・内側曲げ半径・K係数 (パラメータとして式で変更可)
- **面**: 閉じたプロファイルから板厚一定の板を作成 / **フランジ**: 外周エッジ (複数可) に曲げ付きフランジ (外側高さ・角度 0〜150°・方向)。4 辺で箱形状 (角はコーナー逃げ)
- **切り抜き**: 通常の押し出し (切り取り) で穴・切り欠き
- **展開パターン**: 曲げ代 BA = 角度 × (R + K × T) で展開形状を計算し、展開寸法・曲げ線 (山/谷)・面積・質量を表示。DXF (レイヤ OUTER / BEND_UP / BEND_DOWN、レーザー・タレパン用) と SVG に書き出し
- 制限: 展開パターンは基準の面とフランジのみ (後から追加した切り抜きは展開に反映されません)

### 解析・レンダリング

- **応力解析** (検査タブ): 固定面と荷重 (力・圧力・自重) を指定して線形静解析。ミーゼス応力・最大/最小主応力・変位・安全率のコンター、変形表示、凡例、支点反力とつり合い検算、メッシュ収束確認、Markdown レポート
  - **H11 六面体要素** (非適合モード付き): 通常の 8 節点要素の「せん断ロッキング」を解消し、板厚方向 2 要素でも曲げを正確に計算
  - **部分体積補正**: 境界のセルを 4×4×4 でサンプリングして剛性を体積率で補正 (曲面の階段状誤差を低減)
  - **応力回復**: ガウス点応力を節点へ外挿・平均 (表面の最大応力を捕捉)。ボクセルの段差部は内側の値を優先して見かけの応力集中を抑制
  - **マルチグリッド前処理付き共役勾配法**: 反復回数を約 1/50 に削減 (3.7 万要素で 44 秒 → 7 秒)。要素数は体積から自動決定 (細い部材にも要素が入る)
  - **検証** (テストで自動確認): 片持ち梁たわみ ±2% (板厚方向 2 要素)、表面曲げ応力 ±5%、丸棒たわみ ±3%、穴あき板の応力集中係数 (Heywood 2.512) ±5%、引張・圧力・自重の反力つり合い
- **固有値解析**: 固有振動数・モード形状 (アニメーション)・有効質量比 (LOBPCG 法 + マルチグリッド)。片持ち梁 1 次曲げは理論値の 99.8%
- **座屈解析**: 線形座屈の荷重係数と座屈モード (応力剛性行列 + 逆反復)。Euler 柱は理論値の 100.2%
- **熱伝導解析 (定常)**: 温度固定・入熱・対流 (熱伝達率と周囲温度) → 温度分布と熱収支
- **熱応力解析**: 熱伝導の温度分布から熱膨張ひずみを与えて応力・変形を計算 (両端拘束棒 −EαΔT を検証)
- **最大応力部の詳細解析 (サブモデル法)**: 全体解析の変位を境界に与え、最大応力部の周囲だけを約 10 倍細かいメッシュで再解析 (固定面の縁の特異点は除外)。穴あき板の応力集中係数は理論値 (2.512) に対し −0.8%
- **トポロジー最適化**: 固定面・荷重と残す体積の割合を指定すると、最も剛性の高い軽量形状を SIMP 法 (感度フィルター + 最適性規準法) で生成。滑らかな表面 (サーフェス ネット) で表示し、STL 書き出し・モデルへのボディ追加が可能
- **弾塑性解析 (材料非線形)**: 完全弾塑性 (von Mises) の材料で荷重を段階的に加え、割線剛性法で降伏域を計算。降伏した体積・相当塑性ひずみ・荷重–変位曲線を表示し、支えきれない荷重は「塑性崩壊」と判定 (片持ちはりの崩壊荷重は理論値 1.5 F_y に対し 1.3〜1.75 の範囲で検証。降伏域の広がりは要素単位のため、変位の増加はやや小さめに出ます)
- **動的応答解析**: 固有モードの重ね合わせ (高次モードは静的補正) による周波数応答 (共振曲線) と過渡応答 (ステップ・半正弦パルス・正弦波)。減衰比を指定し、応答倍率と動的な応力の目安を表示 (0 Hz で静解析と一致、急に加わる荷重の倍率 ≈ 2 を自動テストで確認)
- **CAM (2.5 軸)**: スケッチのプロファイルからポケット (島の回避・同心オフセット)・輪郭 (外側 / 内側、仕上げ代)・穴あけ (ペック) の工具経路を作成し、3D 表示 (切削: 青 / 早送り: 赤破線)。加工時間の目安と G コード (Fanuc 形式 .nc) の書き出し。工具と治具・残り形状の干渉チェックは行いません
- **3D プリント チェック**: 造形方向・オーバーハング限界角・最小肉厚を指定し、サポートが必要な面 (赤)・薄肉部 (橙) を色分け。開いたエッジ / 非多様体エッジの検出、造形高さ・設置面・体積・質量・造形時間の目安
- **公差累積解析**: 寸法の連鎖 (加算 / 減算) からすき間のワーストケース・統計的 (RSS, 3σ)・モンテカルロ (2 万回) を計算し、各寸法の寄与率と規格内の割合 (ppm) を表示。CSV 書き出し
- **PDF レポート**: 解析条件・結果の表と結果図 (コンター) を A4 の PDF に出力 (Markdown も可)
- **アセンブリ構造解析**: アセンブリ環境から「構造解析」を実行すると、全コンポーネントを接着した一体として解析。部品ごとの材料 (ヤング率・密度) を反映 (鋼+アルミの直列棒で理論値に対し誤差 3% 以内)
- **疲労安全率**: 引張強さから推定した疲労限度による完全両振りの安全率
- **リアル表示** (表示タブ): 床への影・環境の映り込み・金属 / 樹脂の質感でフォトリアルに表示、**高解像度画像** (2 倍解像度 PNG) を保存
- 制限: 応力解析は単一パーツの線形静解析。鋭い入隅・固定面の縁は理論上応力が発散するため値が要素サイズに依存します

### ルール・自動化 (iLogic 相当)

- **ルール**: パラメータ名をそのまま変数として書ける JavaScript 形式のルール (例: `if (幅 > 120) 穴数 = 6;`)。寸法の変更、フィーチャの抑制、iProperty・マテリアルの設定、メッセージ、質量・体積の参照
- 実行タイミング: パラメータ変更時 / 手動 / 保存前。複数ルールは順に実行され、変更は 1 回の「元に戻す」で取り消し可能
- 安全性: ネットワーク・スクリプト読み込みを無効化した専用スレッド (サンドボックス) で実行、3 秒でタイムアウト。ルールを含むファイルを開いたときは実行前に確認
- **ファミリー表** (iPart / デザイン テーブル相当): サイズ違いの構成をパラメータ表で管理し、選んだ行を適用

### 図面環境 (.idw / .slddrw 相当)

「管理 → 図面ビュー」またはファイル メニューの「図面を作成…」で 2D 図面環境に切り替わります。図面はモデルと同じファイルに保存され、モデルを変更すると自動で更新されます。

- **ビュー**: 基準ビュー (正面・平面・側面・等角 など)、投影ビュー (第三角法)、断面図 (A-A、ハッチング付き)、詳細図 (拡大)、隠れ線・中心マークの切り替え、尺度 (JIS 推奨尺度)
- **寸法**: スマート寸法 (長さ・水平・垂直・直径・半径・角度)、穴注記 (4×φ6.6 のように同径穴を自動カウント)、公差 (±、上下偏差、はめあい H7/g6 など、基準・参考寸法)
- **注記**: テキスト、引出線注記、表面性状 (Ra)、幾何公差枠、データム、風船、中心線
- **シート**: A4〜A0・縦横、複数シート、JIS 形式の表題欄 (第三角法記号付き)、アセンブリの部品表
- **出力**: ベクター PDF (全シート)、DXF (AutoCAD / Jw_cad)、SVG
- 元に戻す / やり直し、ドラッグでビュー・注記を移動 (投影ビューは整列を維持)、ダブルクリックで編集
- **図面の自動化**: 自動寸法 (外形・穴の位置をベースライン寸法で・同径穴は「4×φ6.6」にまとめた穴注記・R)、自動風船 (部品表の品番と連動)、**図面セット** (アセンブリから組立図 + 部品ごとの部品図を一括作成し、各シートに表題欄・寸法を自動記入)
- **寸法スタイル**: 自動寸法の穴位置を「並列 (ベースライン)」「直列」「座標 (累進)」から選択。座標寸法は原点からの値を折れ線の引出しで重ならないように記入
- **寸法の重なり回避**: 自動寸法の後に段の割り当て (短い寸法を内側) と引出し寸法の文字の押し出しを自動実行。「寸法を整列」で手動配置の寸法も整理
- **穴テーブル**: 穴に記号 (径ごとに A1, A2 … B1) を付け、原点からの X / Y 座標と径の表を配置
- **面取り注記**: 45° の面取りを検出して「4×C2」のように同サイズをまとめて記入 (自動寸法)
- **溶接記号**: JIS Z 3021 形式 (隅肉・V 形 / レ形 / I 形開先・スポット・プラグ、矢の側 / 反対側 / 両側、寸法・長さ、全周・現場溶接)
- **部分断面 (ブレークアウト)**: ビューの指定範囲を手前から指定の深さまで取り除いて内部を表示 (底面にハッチング、境界はフリーハンド線)
- **部品表の編集**: 部品表をダブルクリックして品番・品名・材質・備考を編集 (数量はアセンブリから自動、品番は風船と連動)
- **階段断面**: 断面図の切断線に段差 (位置・奥行き) を指定し、複数の平面で切断 (切断面すべてにハッチング)
- **破断図**: 長い部品の中間を省略して表示 (JIS の破断線)。寸法は実寸で記入
- **改訂表**: 「管理 → 改訂履歴」で記録した版 (A, B, C …) を表題欄の上に自動表示
- **図面テンプレート**: 会社名・ロゴ画像・設計者・普通公差・用紙サイズを保存して新しい図面に自動適用

## ファイル互換性

| 形式 | 読込 | 書出 | 主な相手先 |
| --- | :-: | :-: | --- |
| STEP (.stp/.step, AP214) | ✓ | ✓ | Inventor / SOLIDWORKS / Fusion 360 / CATIA / Creo / NX / Onshape / FreeCAD (形状 = B-rep ソリッド。部品名・色・アセンブリ構造 (配置) を読み書き) |
| IGES (.igs/.iges) | ✓ | ✓ | 旧来の CAD / CAM — トリム サーフェス (144) と NURBS。名前・色・単位 (inch など) を反映し、平面・円柱・球は解析面に戻す |
| DXF (R12) | ✓ (スケッチとして) | ✓ (スケッチ / 図面 / 展開図) | AutoCAD / Jw_cad / DraftSight / LibreCAD / BricsCAD — 読込: 線分・円・円弧・ポリライン (バルジ)・楕円・スプライン (NURBS)・ブロック挿入、UTF-8 / Shift_JIS 自動判別。書出: JIS 風の画層 (外形線 VISIBLE / かくれ線 HIDDEN / 中心線 CENTER / 細線 / 寸法 / 文字 / ハッチング / 図枠) と線種、日本語は Shift_JIS ($DWGCODEPAGE ANSI_932)、断面ハッチングは 45° の線 |
| STL | ✓ | ✓ | 3D プリンタ、スキャナ |
| 3MF | ✓ | ✓ | Bambu Studio / PrusaSlicer / Cura / Windows 3D ビューアー (ビルド配置・単位を反映) |
| OBJ | ✓ | ✓ | Blender / Rhino / メッシュ系ツール |
| glTF (.gltf / .glb) | ✓ | ✓ | Web・AR・プレゼン・Blender (ノード変換・名前・色、m → mm。.gltf は埋め込みバッファ) |
| PLY | ✓ | ✓ | メッシュ ツール (ASCII / バイナリ)。面のない PLY は点群として表示 |
| E57 (点群) | ✓ (表示・測定) | | レーザー スキャナ (非圧縮の bitPackCodec、Float / ScaledInteger、色・強度、姿勢を反映) |
| IFC (建築) | ✓ (表示・測定) | | Revit / ArchiCAD など (web-ifc で三角形化。IFC を開くときだけ読み込む) |
| BREP | | ✓ | FreeCAD / OpenCascade 系ツール (ネイティブ B-rep) |
| Inventor (.ipt/.iam/.idw/.ipn)・旧 SOLIDWORKS | iProperties・プレビュー | | 形状は非公開形式のため STEP 経由 (読み取った iProperties は現在のパーツに取り込み可能) |
| CSV | ✓ | ✓ | Excel (パラメータ = デザイン テーブル) |
| SVG / PDF (印刷) | | ✓ | 図面 |

メッシュ形式 (STL / OBJ / 3MF / glTF / PLY) の読み込みは三角形を縫合してソリッド化します (編集はできますが面は多面体になります)。点群 (面のない PLY、E57) と IFC は「参照データ」として表示し、点の大きさ・色を変えて、測定コマンドで点と点の距離を測れます。

STEP / IGES の読み込みでは形状を自動で修復します (微小面の削除、隙間の縫合、ワイヤーの修正、面の向きをそろえてソリッド化)。修復した内容は読み込み後に表示されます。

## Inventor との互換性について

| データ | 対応 |
| --- | --- |
| STEP (.stp/.step, AP214) | **読み込み・書き出し両対応**。Inventor で開ける B-rep ソリッドを出力し、Inventor から書き出した STEP をベース フィーチャ / アセンブリ コンポーネントとして読み込めます (アセンブリは部品名付きの複数ソリッド) |
| STL | 読み込み・書き出し (3D プリント用) |
| ネイティブ .ipt / .iam / .idw | 直接は開けません。Autodesk の非公開バイナリ形式で、公式 SDK 以外に仕様が公開されていないためです。Inventor 側で「名前を付けてコピーを保存 → STEP」で書き出して読み込んでください |
| 本アプリ形式 | パーツ `.3dcp`、アセンブリ `.3dca` (JSON。フィーチャ履歴・パラメータ・拘束を保持) |

STEP は形状 (ソリッド) の交換形式のため、フィーチャ履歴やパラメータは Inventor との間では引き継がれません
(これは Inventor 同士以外の CAD 連携で一般的な制約です)。

### 正確性・信頼性・互換性の検証

- **解析の精度**: 片持ちはりのたわみ・応力、穴あき板の応力集中、固有振動数、座屈荷重、熱伝導、弾塑性の崩壊荷重、動的応答 (静的極限・ステップ荷重の倍率 2) を理論解と比較する自動テスト
- **形状の検証**: コイル・曲げパイプ・フレーム・溶接ビード・文字・リブなどの体積や位置を理論値と照合
- **互換性**: STEP 書き出し → 読み込みで体積・表面積・外形寸法が一致 (相対誤差 1e-9)、STL は閉じたメッシュで体積一致、BREP の形式、DXF の Shift_JIS 往復を自動テスト
- **ファイルの信頼性**: 開くときにファイルを検証し、壊れた参照 (存在しない部品・拘束・重複 ID・範囲外の「パーツの終わり」など) は修復して内容を通知。新しいバージョンのフィーチャを含むファイルは、内容を壊さずに理由を表示して開くのを中止。自動保存の失敗 (容量超過) と復元の失敗も通知し、読めなかった自動保存データは別名で保持
- **継続的な検証**: GitHub Actions で push ごとに型チェック・単体テスト (110 件)・ビルド・ブラウザ E2E を実行
