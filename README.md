# 3DCAD Studio

ブラウザで動くパラメトリック 3D CAD です。Autodesk Inventor と同じ考え方・操作感
(スケッチ → フィーチャ → パラメータ、モデル ブラウザ、ViewCube、マーキング メニュー、
アセンブリ拘束) で部品と組立を設計でき、**STEP (AP214) で Inventor とデータを相互にやり取り**できます。

ジオメトリ カーネルには産業用 B-rep カーネル **OpenCascade** (replicad 経由の WebAssembly) を使用しているため、
フィレット・シェル・ブール演算などは近似ではなく正確なソリッドとして計算されます。

## 起動

```bash
npm install
npm run dev        # http://localhost:5173
```

本番ビルド: `npm run build` → `dist/` を任意の静的サーバに配置 (`npm run preview` で確認)。

## できること

### パーツ (.ipt 相当)

| 分類 | 機能 |
| --- | --- |
| 2D スケッチ | 線分 (連続線)・円・3 点円弧・長方形・ポリゴン・長円・点、ジオメトリを投影、トリム、コンストラクション |
| 拘束 | 一致・水平・垂直・平行・直交・同一直線上・正接・等値・同心・中点・対称・固定、自動拘束 (端点スナップ / 水平・垂直推定) |
| 寸法 | 長さ・水平/垂直距離・点-線距離・直径・半径・角度。値は式 (`幅 / 2 + 5 mm` など)、過剰拘束時は従属寸法に自動切替、拘束状態 (残り自由度 / 完全拘束) を表示 |
| 作図中の数値入力 | 線分の長さ、円の直径、長方形の `幅 Tab 高さ` をその場で入力 (寸法も自動作成) |
| フィーチャ | 押し出し (距離 / 貫通 / 対称・反転、接合 / 切り取り / 交差 / 新規ソリッド)、回転 (全周 / 角度、コンストラクション線を軸として自動認識)、ロフト、スイープ、穴 (単純 / 座ぐり / 皿、面クリックで配置)、フィレット、面取り、シェル (内側 / 外側)、矩形状パターン (2 方向)、円形状パターン、ミラー、プリミティブ (直方体・円柱・球・トーラス)、作業平面 (オフセット)、ボディを移動 |
| パラメトリック | すべての寸法・フィーチャ値が `d0, d1, …` のモデル パラメータになり、パラメータ表 (fx) で式・ユーザ パラメータを編集可能。依存関係順に評価し、循環参照を検出 |
| 履歴 | モデル ブラウザ、フィーチャ編集 (ダブルクリック)、抑制、名前変更、パーツの終わり (ドラッグでロールバック)、元に戻す / やり直し |
| 編集時の参照追従 | フィレット等のエッジ / 面参照は寸法変更後も幾何学的に追従 (トポロジ ネーミング対策) |
| 検査 | 測定 (距離・角度・長さ・面積・半径)、iProperties (材質・質量・体積・表面積・重心・範囲) |

### アセンブリ (.iam 相当)

- パーツ (.3dcp) / STEP の配置、同じパーツの複数インスタンス、最初のコンポーネントを自動接地
- 拘束: **メイト・フラッシュ・挿入・軸合わせ・角度** (オフセット / 角度は式で指定可)
- ドラッグで自由移動・自由回転 (拘束は次の解決で再適用)
- コンテキスト内編集: コンポーネントをダブルクリック → パーツを編集 → 「アセンブリに戻る」で全インスタンスに反映
- 部品表 (BOM、CSV 書き出し)、干渉解析、アセンブリの STEP / STL 書き出し

### 図面 (.idw 相当・簡易)

- 正面図・平面図・右側面図 (第三角法、隠れ線付き) と等角図、外形寸法、表題欄を A3 図枠に自動配置
- SVG 書き出し / 印刷 (PDF)

### UI / 操作 (Inventor 準拠)

- リボン (3D モデル / スケッチ (コンテキスト タブ) / 検査 / 管理 / 表示 / 組立)、リッチ ツールチップ
- モデル ブラウザ、プロパティ パネル (OK / キャンセル / 適用+)、ライブ プレビュー
- ViewCube (面・エッジ・コーナー クリック、ドラッグで回転、ホーム)、ナビゲーション バー
- 右クリックの**マーキング メニュー**、中ボタン ドラッグで画面移動、Shift+中ボタン / Alt+左でオービット、カーソル位置へのズーム
- 表示スタイル (エッジ付きシェーディング / シェーディング / 隠れ線 / ワイヤフレーム)、断面図、平行 / 透視投影、ライト / ダーク テーマ
- 自動保存 (ブラウザに保存し、再読み込み時に復元)

主なショートカット (Inventor の既定値に準拠):

| キー | 機能 | キー | 機能 |
| --- | --- | --- | --- |
| `S` | 2D スケッチ | `L` `C` `A` `R` | 線分 / 円 / 円弧 / 長方形 (スケッチ内) |
| `E` | 押し出し | `D` | 寸法 (スケッチ内) |
| `R` | 回転 | `X` | トリム (スケッチ内) |
| `H` | 穴 | `F7` / `F8` | スライス表示 / 拘束表示 |
| `F` | フィレット | `Ctrl+Enter` | スケッチを終了 |
| `Ctrl+Shift+K` | 面取り | `F6` / `Home` | ホーム ビュー / 全体表示 |
| `Ctrl+Shift+R` / `O` / `M` | 矩形状 / 円形状パターン / ミラー | `PageUp` | 注視 |
| `P` / `C` / `V` / `G` | 配置 / 拘束 / 自由移動 / 自由回転 (アセンブリ) | `M` | 測定 |

## Inventor との互換性について

| データ | 対応 |
| --- | --- |
| STEP (.stp/.step, AP214) | **読み込み・書き出し両対応**。Inventor で開ける B-rep ソリッドを出力し、Inventor から書き出した STEP をベース フィーチャ / アセンブリ コンポーネントとして読み込めます (アセンブリは部品名付きの複数ソリッド) |
| STL | 読み込み・書き出し (3D プリント用) |
| ネイティブ .ipt / .iam / .idw | 直接は開けません。Autodesk の非公開バイナリ形式で、公式 SDK 以外に仕様が公開されていないためです。Inventor 側で「名前を付けてコピーを保存 → STEP」で書き出して読み込んでください |
| 本アプリ形式 | パーツ `.3dcp`、アセンブリ `.3dca` (JSON。フィーチャ履歴・パラメータ・拘束を保持) |

STEP は形状 (ソリッド) の交換形式のため、フィーチャ履歴やパラメータは Inventor との間では引き継がれません
(これは Inventor 同士以外の CAD 連携で一般的な制約です)。

## 構成

```
src/
  core/        ドキュメント モデル、式評価、パラメータ、フィーチャ解決、undo/redo ストア
  sketch/      2D 拘束ソルバ (最小ノルム Gauss-Newton)、プロファイル領域検出
  kernel/      OpenCascade ワーカー (B-rep モデリング、メッシュ化、STEP/STL、投影、干渉)
  viewer/      Three.js ビューポート、ViewCube、スケッチ エディタ / 描画
  assembly/    アセンブリ ドキュメント、剛体拘束ソルバ、組立環境
  commands/    フィーチャ コマンド (プロパティ パネル + ライブ プレビュー)
  ui/          リボン、モデル ブラウザ、パネル、ダイアログ、アイコン
```

モデリングはすべて Web Worker 上で行い、フィーチャ単位でキャッシュするため、後ろのフィーチャだけを
変更したときは変更箇所以降のみ再計算されます。
