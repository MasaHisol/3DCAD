# 差分の再計算エンジン (段階 1.5 #3)

## 仕組み
- **依存グラフ** (`src/core/depgraph.ts`): パラメータ → パラメータ / フィーチャ、スケッチ・作業平面・パターン元・サーフェス・参照名 (`e1:side:L3`, `E[…]`) → フィーチャ、ボディの流れ (前のボディ フィーチャ → 次)。`affectedFeatures(prev, next)` が編集・追加・削除・並べ替え・抑制・ロールバックの影響範囲を返す。
- **状態キャッシュ** (`src/kernel/rebuildCache.ts`, `GeometryEngine.rebuild`): フィーチャ i 後の状態 (ボディ・ツール・サーフェス・参照名) を「フィーチャ 0..i の内容」のハッシュ鍵で保存。再計算は全状態がキャッシュにある最長の先頭部分から再開する。現在のモデルの状態は固定、それ以外 (元に戻す・やり直し・抑制前など) は `GeometryEngine.maxExtraStates` (既定 160) 件まで保持し、古い版から、版の中では後ろのフィーチャから捨てる。捨てた状態の OCC 形状は他の状態が使っていなければ `.delete()` で解放。表示メッシュも形状ごとに再利用。
- **位相探索の高速化** (`src/kernel/topo.ts`): replicad の `faces`/`edges` の O(n²) 重複除去をハッシュで O(n) に置換 (同じ順序・同じ要素)。参照名の辺→面表と面の記述も再利用。
- **並列再構築** (`src/kernel/pool.ts`): 部品が 2 つ以上あるアセンブリを開くとき、空きコア数 (最大 4、メモリ 2 GB あたり 1) のワーカーで表示メッシュを並列に作る。B-rep は必要時 (`ensureBrep`) と読み込み後の裏でメイン ワーカーに作る。各ワーカーは `KernelClient` なので異常終了時は再起動して 1 回だけ再試行、失敗した部品はメイン ワーカーで作る。30 秒使わないとワーカーを止める。
- **検証モード**: `GeometryEngine.verify = true` (ワーカーは `VITE_VERIFY_REBUILD=1` でビルド) で差分再計算のたびに全再計算と体積・面数・辺数・参照名表を比較し、違えば例外。

## 計測
`npm run bench:rebuild` (部品)、`npm run e2e:rebuild` (アセンブリの初回読み込み、逐次と並列)。
