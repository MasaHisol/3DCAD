# 3DCAD Studio で学ぶ 3D 設計 — 基礎コース 教材

3DCAD Studio に組み込まれた **学習センター** (タイトルバーの「🎓 学習」、または起動画面の「3D 設計を学ぶ」) で、
実際に手を動かしながら 3D 設計を基礎から学べます。この文書は、その内容を紙でも読める形にまとめた教材と、
授業・社内研修で使うための手引きです。

## 座学テキスト (別アプリ)

操作の実習とは別に、**設計の考え方と理論を学ぶ座学テキスト** (`textbook.html`) があります。
CAD とは別のウィンドウ (ブラウザ版は別タブ) で開き、CAD を操作しながら横に並べて読めます。

- 開き方: 学習センターの「座学テキスト」ボタン、ファイル メニュー、コマンド検索 (`Ctrl+K` →「テキスト」)、デスクトップ版はメニューの「ヘルプ → 座学テキスト」

## アプリでのレッスンの進み方

1. **解説** — その回の考え方 (なぜそうするのか) と目標を読みます
2. **操作** — 画面右下のガイドの指示に従って操作します
   - 使うボタンはリボン上で **オレンジ色に光って** 表示されます (必要なタブにも自動で切り替わります)
   - 操作が終わると、アプリがモデルの状態 (フィーチャ・寸法・拘束・図面など) を見て **自動で判定** し、次のステップへ進みます
   - 進まないときは「ヒントを見る」、どうしても進めないときは「スキップ」。操作を間違えたら `Ctrl+Z`
3. **ふりかえり** — 大切なポイントを確認します
4. **確認テスト** — 2〜3 問のクイズ。点数 (最高点) が学習センターに記録されます

各レッスンは専用の練習モデル (空のパーツ、60 × 40 × 15 のブロック、取付プレート、サンプルのブラケット、ピンの組立など)
から始まるので、どのレッスンからでも単独で取り組めます。作業中のモデルは先に保存してください。

進捗 (完了したレッスン・テストの点数・達成した演習) は、そのコンピュータのアプリ (ブラウザ) に保存されます。
学習センターの「進捗をリセット」で消去できます。

## 各章のポイント (読み物)

### 第 1 章 はじめの一歩

- **3D CAD** は部品の形を中身の詰まった **ソリッド** として作る。体積・質量・重心が正確にわかり、図面・解析・3D プリント・NC 加工にそのまま使える
- このアプリは **パラメトリック フィーチャ ベース**: 形は「スケッチ → 押し出し → 穴 → フィレット …」という **フィーチャの履歴** で記録され、寸法 (パラメータ) を変えると上から順に再計算される
- 寸法は `d0, d1 …` や `幅` のような **パラメータ**。**式** (`幅 / 2 + 5`) でつなぐと「穴はいつも中央」のような **設計意図** を保てる
- 視点操作: 回転 = `Shift`+中ボタン (または `Alt`+左)、移動 = 中ボタン、ズーム = ホイール、`F6` = ホーム ビュー

### 第 2 章 スケッチ

- 立体の元になる 2D の輪郭。基準平面 (XY・YZ・XZ) か、立体の平らな面に描く。**Y 軸が上** なので水平面は **XZ 平面**
- **幾何拘束** (水平・垂直・平行・直交・一致・正接・等値・同心 …) は形の関係、**寸法拘束** は大きさと位置
- 平面上の点の自由度は 2。拘束と寸法で自由度を 0 にした **完全拘束** の状態にしておくと、寸法変更で形が崩れない
- **コンストラクション線** は輪郭にならない補助線。回転軸・対称軸・寸法の基準に使う

### 第 3 章 基本フィーチャ

- **押し出し**: プロファイルを平面に垂直に伸ばす。範囲 (距離・対称・貫通) と演算 (新規・接合・切り取り・交差 = **ブール演算**)
- **穴**: 座ぐり・皿穴・ボルト用キリ穴 (M6 → Ø6.6)・ねじ穴を規格寸法で作る。図面に穴注記が入る
- **回転**: 断面を軸のまわりに回す。断面は軸の片側に閉じた形で描く
- **フィレット** (丸め) は応力集中の緩和と安全、**面取り** (C2 = 2 mm × 45°) は組立のガイドとバリ取り、**シェル** は一定肉厚の中空化。フィレット → シェルの順が基本
- **パターン / ミラー** は元フィーチャのコピー。元を直すとすべて変わる (対象は 押し出し・回転・穴・プリミティブ)

### 第 4 章 パラメトリック設計と検証

- **ユーザ パラメータ** (`幅`, `板厚` …) を作り、寸法の式から参照する → サイズ違いを値の変更だけで作れる
- 質量 [g] = 体積 [cm³] × 密度 [g/cm³]。鋼 7.85、アルミ 2.7、ABS 1.05
- **測定** で距離・角度・長さ・面積・半径を確認

### 第 5 章 アセンブリ

- 空間の剛体は **6 自由度** (移動 3 + 回転 3)。最初の部品は **接地**
- 拘束: メイト (面を向かい合わせ)・フラッシュ (面をそろえる)・**挿入** (軸 + 面の接触: ボルト・ピン)・軸合わせ・角度
- 動く部品は自由度を残す。**部品表** と **干渉解析** で組立を検証

### 第 6 章 図面

- JIS は **第三角法**: 平面図は正面図の上、右側面図は右
- 寸法は加工・検査に必要なものを重複なく。内部の形は **断面図** (ハッチング)
- 表題欄 (図名・図番・材料・尺度・設計者・日付)。モデルを変えると図面も自動更新

### 第 6 章 (続) CAD 製図を極める

- 小さな部分は **詳細図** (識別文字と尺度)、穴・対称形には **中心線** (細い一点鎖線)、同じ穴は **4×φ9** とまとめる
- 公差は機能寸法にだけ。はめあいは記号 (H7/g6)、その他は **普通公差** (JIS B 0405) で一括指示
- 形・姿勢・位置は **幾何公差** とデータムで。表面性状 (Ra) は機能のある面だけ細かく
- 内部は断面で: **部分断面**・**破断図**。軸・ボルト・リブは長手方向に切っても断面にしない
- 穴の多い部品は **座標寸法** や **穴テーブル**。組立図には **部品表** と **風船**

### 第 7 章 解析と製造

- **応力解析 (FEA)**: 固定 + 荷重 → ミーゼス応力・変位・安全率。安全率 = 降伏応力 ÷ 最大応力 (目安 2〜3 以上)
- 鋭い角は応力集中で値がメッシュに依存 → フィレットで改善
- 形式の使い分け: **STEP** (正確なソリッド: 他 CAD・CAM・外注)、**STL / 3MF** (メッシュ: 3D プリント)、**DXF / PDF** (2D: 図面・レーザー加工)
- 3D プリントは約 45° を超える **オーバーハング** にサポートが必要。造形方向を工夫する

## 授業・研修で使うときの手引き

- **準備**: 受講者の PC にアプリをインストールしておきます (インターネット接続は不要)
- **1 コマ目 (入門)**: 第 1〜2 章。最初の 10 分で講師が画面操作を実演し、その後は各自でレッスンを進めます
- **2 コマ目 (基礎)**: 第 3〜4 章。早く終わった人は総合演習 1 へ
- **3 コマ目 (応用)**: 第 5〜7 章 + 総合演習 2・3 を課題に
- **4 コマ目 (発展)**: 第 8 章 + 総合演習 4〜6。座学テキストの第 3 部 (機械要素) と組み合わせると、機構設計の課題にできます
- **座学**: 座学テキストは 1 章 15〜25 分。授業前の予習・授業後の復習に、各章の計算練習と確認テストを使えます
- **評価**: 学習センターの「コース」タブで完了レッスン数とテストの点数、「総合演習」タブで達成状況が確認できます。
  演習の成果物は `.3dcp` ファイルと図面の PDF で提出してもらうと評価しやすくなります
- **つまずきやすい所**: スケッチ平面の選択 (XZ が水平面)、完全拘束 (原点との位置関係を忘れやすい)、
  回転の断面が軸をまたぐ、シェルで取り除く面の選択 (ViewCube で底面を見る)、挿入拘束で選ぶ円形エッジ

## 開発者向け: レッスンの追加方法

教材はすべてソースの中にデータとして書かれています。

| ファイル | 内容 |
| --- | --- |
| `src/learn/curriculum.ts` | 章・レッスン (目標・解説・手順・ふりかえり・確認テスト)、総合演習、用語集 |
| `src/learn/checks.ts` | ステップの判定に使う関数 (`has(s, "fillet")`, `hasDim(s, sk, 40)`, `usesUserParam(s)` など) |
| `src/learn/starters.ts` | レッスンの開始モデル (ブロック・プレート・ピン組立) |
| `src/learn/tutor.ts` | 右下のガイド (状態の監視・自動判定・ボタンの強調・テスト) |
| `src/learn/center.ts` | 学習センターのダイアログ |
| `tests/learn.test.ts` | カリキュラムの整合性 (存在するボタンだけを指しているか等) と判定関数のテスト |
| `textbook.html`, `src/textbook/` | 座学テキスト (`content/` に章の本文、`widgets.ts` に計算ツール、`mech.ts` に計算式) |
| `tests/textbook.test.ts`, `tests/mech.test.ts` | テキストの整合性 (計算ツール・レッスンへのリンク) と計算式の検証 |

ステップは次のように書きます。`check` はアプリの状態 (`LearnState`: パーツ / アセンブリ文書、パラメータの値、実行中のコマンド、
編集中のスケッチの自由度、表示スタイルなど) を受け取る純粋な関数で、`true` を返すと次へ進みます。省略すると「次へ」ボタンで進む説明ステップになります。

```ts
{
  text: "<b>フィレット</b> (<kbd>F</kbd>) で縦の 4 本のエッジを半径 <code>5</code> で丸めます。",
  tab: "model",          // 前面に出すリボン タブ
  ui: "fillet",          // 強調するボタン (data-cmd)。CSS セレクタも可
  check: (s) => has<FilletFeature>(s, "fillet", (f) => f.edges.length >= 1),
  hint: "ビューを回して裏側のエッジも選びましょう。",
}
```

フィーチャのコマンドはプレビューのために実行中からフィーチャを文書に書き込むため、`has()` / `features()` は
そのコマンドが開いている間は最新のフィーチャを数えません (OK を押した時点で判定されます)。
