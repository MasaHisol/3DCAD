# 3DCAD Studio 機能アップデート 統合予定表 (改訂 3)

保留中の 25 項目と、CAD ビューア強化の 11 項目 (eDrawings 比較) をまとめて、優先順位を見直しました。
**まだ実装はしていません。** 各段階の終わりで作業を止め、結果を報告してから次へ進みます。

## 優先順位の決め方
1. **土台を先に**: 大規模データ・多形式・安定性が弱いと、上に載るビューア機能が使えない
2. **すぐ価値が出るものを先に**: ビューア・レビュー機能は既存の形状データを「見る・指摘する・配る」だけで成立し、モデリングカーネルの大改修を待たずに効果が出る
3. **依存関係**: 図面の 2D-3D 連動は図面機能の改善と、組立アニメは機構機能と、マークアップの面への固定は形状参照の安定化と関係する
4. **リスクの高いもの (ライセンス・外部ライブラリ) は調査を先に行い、実装は後ろへ**

### 前回の予定からの主な変更
- ビューア・レビュー機能 (段階 2・3) を、モデリング強化 (旧段階 2) より前に置いた。既存データですぐ使え、利用者が多いため
- 形状の安定化は段階 1 から段階 6 へ移した。モデリングの編集と一体で行う方が効率がよく、ビューア機能の前提ではないため (マークアップのピンは、改訂をまたいだ追従を段階 6 で強化する)
- 「互換性向上」「データ交換の品質」「形式の追加」を段階 1 にまとめた
- 「図面の比較」と「3D の比較」は差分表示の仕組みを共有するが、3D 側を先に作る (段階 3)。図面側は段階 4 で流用する
- 組立手順アニメーションは機構の仕組みと共通部分が多いので段階 5 にまとめた

## 段階 1 基盤 (大規模・多形式・安定性)
| 項目 | 内容 | 完了の条件 |
|---|---|---|
| 安定性 | 自動保存と異常終了後の復元、操作ログ、カーネルエラー時に直前の状態へ戻す | 強制終了後に復元できる (e2e テスト) |
| 表示性能 | 描画の一括化、表示の簡略化 (LOD)、選択判定の高速化、大規模データを軽量表示で開く (詳細は必要な部品だけ読み込む) | 大規模サンプルで開く時間と回転のフレームレートを計測し改善 |
| データ交換の品質 | STEP の色・名前・構造の往復、読み込み形状の自動修復 | 代表サンプルの往復テストに合格 |
| 形式の追加 | IGES (カーネルの対応を確認)、glTF の読み書き、IFC (建築データ、外部ライブラリ使用)、点群 PLY・E57 の表示 | 各形式のサンプルを開いて表示・測定できる |

**要調査 (実装可否を先に判断)**
- **JT**: 無償で使える読み込みライブラリがなく、実装できない可能性が高い
- **DWG**: 無償ライブラリはライセンス (GPL) の制約があり、商用配布と両立しない可能性がある。有償ライブラリか DXF 変換経由かを判断する (段階 4 の DWG 表示にも影響)
- **Parasolid・SolidWorks などの独自形式**: 対象外 (ライブラリの都合)

## 段階 1.5 エンジン基盤 (独自エンジン #1〜#3)
| 項目 | 内容 | 完了の条件 |
|---|---|---|
| #1 OCC カーネルのカスタムビルド | IGES・XCAF 読み込み・ShapeFix_Shape・HLR などを含むカーネルを用意 (自前ビルド、または機能の多い公開ビルドを必要時に読み込む)。呼べない関数の解消 | 標準の修復・IGES・XCAF STEP 読み込みがカーネルで動く。既存テストがすべて通る |
| #2 形状の参照名エンジン | 面・辺に由来に基づく名前を付け、編集後も同じ要素を追跡 (フィレット・穴・寸法・組立拘束・ピンの参照) | 上流の編集で下流の参照が外れない回帰テストに合格 |
| #3 差分の再計算エンジン | 依存グラフで変更箇所だけ再計算、部品ごとの並列再構築 (計算スレッドの複数化) | 大きなモデルで編集後の再計算時間と、アセンブリの初回読み込み時間が短縮 |

**残りのエンジンの組み込み先**: #4 描画エンジン (WebGPU) と #5 テッセレーション・LOD は段階 2、#10 形状比較は段階 3、#6 図面の投影・隠線は段階 4、#7 拘束ソルバは段階 6、#8 解析ソルバは段階 7 で、その段階の機能と一緒に実装します。

## 段階 2 ビューアの中核
| 項目 | 内容 | 完了の条件 |
|---|---|---|
| #4 描画エンジン (WebGPU) | GPU 選択判定・半透明の正しい表示・断面の塗りつぶし・大規模描画、WebGL への自動切替 | 同じ大規模サンプルで描画性能が段階 1 の値を上回る |
| #5 テッセレーション・LOD | 曲率に応じた分割・段階的な詳細表示・キャッシュ管理 (更新と整理) | 表示誤差を指定値以内に保ったまま三角形数を削減 |
| 閲覧専用モード | 編集 UI を隠した軽い起動モード、STEP・IGES・glTF・メッシュなどもダブルクリックで直接開く (既存の .3dcp/.3dca の関連付けを拡張) | 関連付けたファイルから閲覧モードで開く。起動時間を計測 |
| 測定の強化 | 穴径・ピッチ円・肉厚の分布・最小距離・クリアランス、測定結果を注記として保存 | 各測定が理論値と一致。保存した注記が再表示される |
| 断面の強化 | 3 平面の同時断面、断面の塗りつぶしとハッチング、断面位置のアニメーション、断面形状の DXF 出力 | 3 平面で切って断面形状を DXF に出力できる |
| アセンブリの閲覧 | 部品表と 3D の連動選択、部品の分離表示、表示状態 (ビュー) の保存、干渉チェックの強化、部品ごとの色分け | 保存したビューを呼び出すと表示状態が再現される |
| 使い方ヘルプ | 機能ごとの使い方ページ、操作の動画・図解、ツールチップから該当ヘルプへ移動 | 全コマンドにヘルプがある |

## 段階 3 レビューと配布
| 項目 | 内容 | 完了の条件 |
|---|---|---|
| マークアップ | 3D の面・辺に付くコメントのピン、手書き・矢印・雲マーク・寸法付きの指摘、スタンプ (承認・差戻し)、状態管理 (未対応・対応済み・確認済み)、一覧から該当箇所へ移動、指摘レポートの PDF・CSV 出力 | 指摘を付けて保存・再読み込み・状態変更・レポート出力ができる |
| 1 ファイル HTML ビューア | ブラウザだけで 3D・図面・PMI・測定・マークアップ表示、測定の可否、パスワード (データ自体を暗号化)、有効期限 | 書き出した HTML がオフラインのブラウザで開き、設定どおり制限される |
| 3D の比較 (#10 形状比較エンジン) | 形状差の色分け (追加・削除・変更)、ずれ量のヒートマップ、部品構成の差分 | 改訂前後のサンプルで差分を正しく表示 |

**注意**: HTML の有効期限は閲覧側の時計で判定するため、厳密な失効にはならない (パスワード暗号化は有効)。

## 段階 4 図面
| 項目 | 内容 | 完了の条件 |
|---|---|---|
| DWG・PDF 図面の表示 | PDF 図面の表示、DWG は段階 1 の調査結果に従う | サンプル図面を開いて拡大・測定できる |
| #6 図面の投影・隠線エンジン | 正確で速い隠線処理とビューの部分更新 | 代表図面のビュー作成時間を短縮し、隠線が正しい |
| 2D と 3D の連動 | 図面の寸法・ビューをクリックすると 3D の該当箇所を表示 (自前の図面が対象) | 寸法から 3D の面・辺がハイライトされる |
| 図面の自動作成 | 投影図・断面図・寸法の自動配置 | 代表部品で自動作図し、寸法の不足がない |
| JIS・ISO の自動チェック | 線種・寸法の重複と不足・公差の記入漏れ・表題欄の検出 | 誤りを仕込んだ図面で全項目を検出 |
| 3D 図面 | PMI を STEP AP242 で出力 | 書き出した STEP に PMI が含まれる |
| 図面の比較 | 段階 3 の比較の仕組みを図面に流用 | 寸法・形状の変更を検出 |
| 検図ドリル (学習) | 自動チェックを流用した間違い探し | 学習センターで採点できる |

## 各段階の進め方
1. 調査と設計 (要調査項目は可否を先に報告)
2. 実装
3. 単体テスト・e2e テスト・画面での動作確認
4. PR と CI 合格後にマージ
5. 結果を報告して中断 (次の段階は指示を受けてから開始)
