# 3DCAD Studio 超大型アップデート 予定表

依頼された 25 項目を、依存関係と効果の大きさから 6 段階に分けました。
各段階の終わりで作業を止め、テスト・動作確認の結果を報告してから次へ進みます。

| 段階 | テーマ | 項目 | 主な理由 |
|---|---|---|---|
| 1 | 基盤と信頼性 | 安定性 / 形状の安定化 / 互換性向上・データ交換の品質 / 表示性能 | すべての機能の土台。壊れない・速い・他社 CAD とやり取りできる |
| 2 | モデリング | スケッチの強化 / パラメトリック化 / ダイレクト編集 / 専用フィーチャ | 毎日の作図・モデリング作業の速さに直結 |
| 3 | アセンブリと機構 | アセンブリ上の設計 / 締結具とライブラリ / 機構シミュレーション / 機構シミュレータ (学習) | 装置設計の中心。段階 2 の参照の安定化が前提 |
| 4 | 図面 | 図面の自動作成 / JIS・ISO の自動チェック / 3D 図面 / 図面の比較 / 図面の間違い探し・検図ドリル (学習) | 出図の工数削減。チェック機能をドリルにも流用 |
| 5 | 解析と製造 | 適応メッシュ / 形状最適化 / 板金の自動処理 / 加工しやすさの自動判定 (DFM) | 設計品質と製造への受け渡し |
| 6 | 操作性と学習体験 | コマンド提案 / カスタマイズ / 全文検索・用語集・公式集 | 全機能がそろってから仕上げる |

互換性向上とデータ交換の品質は同じ作業なので段階 1 にまとめました。
機構シミュレーション (CAD 機能) と機構シミュレータ (学習教材) は同じ計算エンジンを使うので段階 3 にまとめました。

---

## 段階 1 基盤と信頼性

| 項目 | 内容 | 完了の条件 |
|---|---|---|
| 安定性 | 自動保存と異常終了後の復元、操作ログの記録、カーネル (OCC) エラー時に直前の状態へ戻す、長時間操作でのメモリ確認 | 強制終了後に復元できる。e2e テストに復元シナリオを追加して合格 |
| 形状の安定化 | 面・辺の参照名を形状の由来で付け直す (トポロジ名付け)、再計算エラー時の原因表示と修復候補 (参照の付け替え・フィーチャの抑制) | 上流の寸法変更・フィーチャ追加で下流のフィレット・穴が外れないことを回帰テストで確認 |
| 互換性向上・データ交換の品質 | STEP の色・名前・アセンブリ構造の読み書き、IGES・DXF/DWG の改善、読み込み形状の自動修復 (隙間・小さな面・向き) | 代表的な STEP/IGES/DXF サンプルの往復で形状・構造が保たれるテストに合格 |
| 表示性能 | 描画の一括化 (インスタンス化・メッシュ結合)、表示の簡略化 (LOD)、選択判定の高速化 | 大規模アセンブリのサンプルで回転操作のフレームレートを計測し、改善前より向上 |

## 段階 2 モデリング

| 項目 | 内容 | 完了の条件 |
|---|---|---|
| スケッチの強化 | 拘束の過不足を色で表示、冗長拘束の検出、スプラインの曲率表示、ブロック化、DXF 下絵のトレース | 拘束ソルバの単体テスト追加。完全拘束・過拘束の判定が正しい |
| パラメトリック化 | 方程式 (パラメータ間の式)、設計表 (既存のファミリー表の拡張)、構成 (1 モデルで複数の型番) | 構成を切り替えると形状・質量・図面が追従する |
| ダイレクト編集 | 面の移動・オフセット・置き換え・削除、穴やフィレットの検出と削除 (読み込み形状にも適用) | 読み込んだ STEP 形状の面を動かし、穴を消せる |
| 専用フィーチャ | 溶接構造 (形鋼フレーム・ガセット・溶接記号)、樹脂部品 (ボス・リブ・スナップ)、勾配・アンダーカット解析 | 各フィーチャの作成・編集・再計算のテストに合格 |

## 段階 3 アセンブリと機構

| 項目 | 内容 | 完了の条件 |
|---|---|---|
| アセンブリ上の設計 | 相手部品を参照した部品の作成、参照の追従と参照の固定・解除 | 相手部品の変更に合わせて参照した形状が更新される |
| 締結具とライブラリ | 穴を認識してボルト・ナット・座金を一括挿入、ボルト長さの自動選定、軸受・ピンの追加 | 穴パターンに合わせて締結具が自動配置される |
| 機構シミュレーション | 歯車・カム・ねじの拘束、モーター駆動曲線、反力・トルクのグラフ、サーボ選定との連携 | 減速機・ボールねじ・カムのサンプルで、理論値とシミュレーション値が一致 |
| 機構シミュレータ (学習) | 座学から開くリンク・カム・歯車・ボールねじの組立シミュレータ (同じエンジンを使用) | 関連する章に組み込み、操作して値が確認できる |

## 段階 4 図面

| 項目 | 内容 | 完了の条件 |
|---|---|---|
| 図面の自動作成 | 必要な投影図・断面図の自動選択、寸法の自動配置 (機能寸法を優先) | 代表部品で自動作図し、寸法の不足がない |
| JIS・ISO の自動チェック | 線種・寸法の重複と不足・公差の記入漏れ・表題欄の検出、指摘一覧から該当箇所へ移動 | 誤りを仕込んだ図面で全項目を検出 |
| 3D 図面 | MBD の PMI を STEP AP242 で出力、3D 図面の表示状態の保存 | 書き出した STEP に PMI が含まれる |
| 図面の比較 | 改訂前後の図面の差分を色表示、改訂履歴との連携 | 寸法・形状の変更を検出して表示 |
| 図面の間違い探し・検図ドリル (学習) | 自動チェック機能を流用した検図ドリル (時間制限・採点) | 学習センターに組み込み、採点が動作 |

## 段階 5 解析と製造

| 項目 | 内容 | 完了の条件 |
|---|---|---|
| 適応メッシュ | 誤差の大きい要素を自動で細分化し、結果が収束するまで再計算 | 応力集中のサンプルで理論値に収束 |
| 形状最適化 | 既存のトポロジ最適化の改善と、寸法の最適化 (パラメトリックスタディ) | 指定した条件で質量が減り、応力が許容値内 |
| 板金の自動処理 | 曲げ順の検証、展開図の DXF 出力の強化、ネスティング (板取り) | 複数部品の板取りと曲げ干渉の検出 |
| 加工しやすさの自動判定 (DFM) | 切削 (深穴・入隅 R・工具の届き)、板金、樹脂 (肉厚・勾配) の判定 | 問題箇所を色付けして一覧表示 |

## 段階 6 操作性と学習体験

| 項目 | 内容 | 完了の条件 |
|---|---|---|
| コマンド提案 | 選択内容と直前の操作から次のコマンドを提案 | 主要な作業の流れで提案が表示される |
| カスタマイズ | ショートカット・リボン・マウス操作の変更、プリセット、設定の書き出しと読み込み | 設定が保存・復元される |
| 全文検索・用語集・公式集 | 座学 307 章・レッスン・用語の全文検索、公式集ページ、用語にカーソルを合わせると説明 | 検索結果から該当箇所へ移動できる |

---

## 各段階の進め方
1. 既存コードの調査と設計
2. 実装 (項目ごとに分担)
3. 単体テスト・e2e テスト・ブラウザでの動作確認
4. コミットと PR、CI 合格後にマージ
5. 結果を報告して中断 (次の段階は指示を受けてから開始)
